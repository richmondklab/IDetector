À propos

Notre mission : rendre le Mobile Money plus sûr pour tous.

iDetector est un projet de détection de fraude né en Côte d'Ivoire, conçu pour protéger les utilisateurs de services financiers mobiles en Afrique de l'Ouest.

Un constat

Le Mobile Money a rapproché des millions de personnes des services financiers. Les fraudeurs l'ont aussi compris : faux transferts, faux agents, faux liens de blocage de compte se propagent par SMS, WhatsApp et appels vocaux.

Notre approche

Nous combinons des règles d'analyse issues de cas réels, la signalisation communautaire et, à terme, des modèles d'apprentissage automatique entraînés sur des exemples annotés localement, en français et dans le contexte linguistique ouest-africain.

Nos principes

Transparence sur ce que l'outil sait et ne sait pas faire, respect de la vie privée dès la conception, gratuité pour le grand public et ouverture aux développeurs et aux opérateurs partenaires.

FAQ

Questions fréquentes sur les arnaques Mobile Money

Qu'est-ce qu'un « faux transfert » ?

Vous recevez un SMS imitant une confirmation de dépôt, puis un appel ou un message vous demande de « renvoyer l'argent envoyé par erreur ». Or aucun dépôt réel n'a eu lieu : en renvoyant la somme, vous perdez votre propre argent. Vérifiez toujours votre solde depuis l'application officielle ou le code USSD de votre opérateur.

Comment reconnaître un faux agent ou faux service client ?

Il vous contacte sans que vous l'ayez demandé, crée un sentiment d'urgence et réclame votre code secret, un code reçu par SMS (OTP) ou une « vérification » d'identité. Un véritable agent ne vous demandera jamais votre code secret. Raccrochez et rappelez le numéro officiel de votre opérateur.

Que faire si je reçois un lien disant que mon compte est bloqué ?

Ne cliquez pas. Les opérateurs ne rétablissent pas un compte via un lien reçu par SMS. Ouvrez l'application officielle ou contactez le service client par ses canaux officiels. Les adresses qui imitent un nom connu (ex. avec des tirets ou des extensions inhabituelles) sont un signal d'alerte majeur.

J'ai déjà communiqué mon code ou envoyé de l'argent. Que faire ?
  1. Contactez immédiatement votre opérateur pour bloquer le compte et signaler la transaction.
  2. Changez votre code secret depuis un canal officiel.
  3. Conservez les captures d'écran, numéros et horodatages.
  4. Déposez plainte auprès des autorités compétentes de votre pays (en Côte d'Ivoire : la plateforme de lutte contre la cybercriminalité de la Police nationale).
iDetector peut-il se tromper ?

Oui. L'analyse repose sur des indicateurs et ne peut pas tout détecter, notamment les arnaques très récentes ou les conversations sans lien ni mot-clé évident. Un faux positif est possible, et un message jugé peu risqué n'est pas une garantie de sécurité.

Mes messages sont-ils conservés ?

Non. Le texte analysé est transmis à notre serveur, puis à un fournisseur d'IA, mais son contenu n'est pas conservé : seules des statistiques sans contenu (date, type d'arnaque, niveau de risque, indice de confiance) sont enregistrées. Un message n'est conservé que si vous choisissez de le signaler via la page « Contribuer ».

Communauté

Signalez une arnaque, protégez les autres.

Chaque signalement aide à repérer de nouveaux schémas de fraude et à améliorer la détection pour tout le monde.

Comment bien signaler

  1. Copiez le texte exact du message reçu.
  2. Masquez tout élément personnel : votre nom, votre numéro, votre solde.
  3. Indiquez le canal, le service imité et le numéro ou le lien de l'expéditeur.
  4. Ne cliquez jamais sur le lien et ne rappelez pas l'expéditeur.
Vous avez déjà perdu de l'argent ? Contactez d'abord votre opérateur et les autorités ; ce formulaire ne permet pas de récupérer des fonds.

Documentation de l'API iDetector

Intégrez l'analyse anti-arnaque dans votre application, votre bot WhatsApp ou le back-office de votre service. Cette page décrit l'API REST utilisée par le site.

Cette API est celle qui alimente l'analyseur de ce site. Remplacez l'adresse de base par celle de votre déploiement.

URL de base et accès

Base URL : https://VOTRE-DOMAINE/api
Auth     : aucune pour l'analyse (limitée par adresse IP)
Format   : application/json (UTF-8)
POST/analyze

Analyse un message (texte et/ou capture d'écran) et renvoie le niveau de risque, le type d'arnaque, une analyse et une recommandation.

Requête

curl -X POST https://VOTRE-DOMAINE/api/analyze \
  -H "Content-Type: application/json" \
  -d '{
    "text": "Votre compte est bloqué. Cliquez sur http://wave-verif.xyz",
    "lang": "fr"
  }'
ChampTypeDescription
textstringMessage à analyser (2 000 caractères max). Obligatoire si aucune image n'est envoyée.
langstring« fr » ou « en ». Langue des explications renvoyées. Défaut : « fr ».
imagefichierCapture d'écran PNG, JPG ou WebP (8 Mo max). Uniquement en multipart/form-data, seule ou avec « text ».

Réponse 200

{
  "analysisId": 1288,
  "riskLevel": "Élevé",
  "scamType": "Faux message de blocage de compte (Wave)",
  "confidenceScore": 92,
  "analysis": "Le lien imite le nom d'un service connu et le message menace de bloquer le compte.",
  "recommendation": "Ne cliquez pas. Contactez votre opérateur par un canal officiel."
}

riskLevel : Faible · Moyen · Élevé  |  confidenceScore : 0 – 100

Mentions légales

Politique de confidentialité et droits d'auteur

Dernière mise à jour : 20 octobre 2026

1. Données traitées

Le texte que vous soumettez à l'analyseur est envoyé à notre serveur, puis à un fournisseur d'intelligence artificielle (le service d'IA configuré par iDetector) uniquement pour produire l'analyse. Le contenu du message n'est pas conservé : nous enregistrons seulement des données statistiques (date, type d'arnaque, niveau de risque, indice de confiance, durée de traitement). Les captures d'écran sont lues dans votre navigateur (OCR) : l'image n'est pas envoyée, seul le texte extrait l'est. Si l'IA est indisponible, une analyse locale simplifiée est effectuée dans votre navigateur. Ne saisissez jamais de code secret, mot de passe ni donnée personnelle.

2. Signalements communautaires

Si vous utilisez la page « Contribuer », les informations que vous renseignez (type d'arnaque, contenu du message, numéro ou lien de l'expéditeur) sont utilisées uniquement pour améliorer la détection des fraudes. N'y incluez jamais de code secret, de mot de passe ni de données personnelles.

3. Stockage local

Votre préférence de langue peut être enregistrée dans le stockage local de votre navigateur. Vous pouvez la supprimer à tout moment depuis les réglages de votre navigateur.

4. Cookies et traceurs

iDetector n'utilise aucun cookie publicitaire ni traceur de profilage.

5. Vos droits

Conformément à la législation applicable en matière de protection des données personnelles (notamment la loi ivoirienne n° 2013-450 et les textes équivalents des pays concernés), vous disposez d'un droit d'accès, de rectification et de suppression. Écrivez-nous à l'adresse de support indiquée en bas de page.

6. Limitation de responsabilité

Les résultats de l'analyse sont fournis à titre indicatif. iDetector ne peut être tenu responsable des décisions prises sur leur seule base.
